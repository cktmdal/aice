딥러닝 학습

스트레스 수준은 "object"로 데이터 유형 category, 디코더 선택 sparse로 한다
컴퓨터는 문자나 단어를 직접 이해하지 못하기 때문에, 범주형 데이터를 학습할 때 원-핫 인코딩(One-Hot Encoding)이라는 방식을 거칩니다.
sparse 디코더를 선택하면, 컴퓨터에게 "0이 아닌 중요한 값(1)의 위치만 압축해서 기억하고, 나머지 수많은 0들은 굳이 메모리에 다 차지게 저장하지 마!" 라고 지시하는 것과 같습니다.
학습 속도도 빨라지고 메모리와 성능의 낭비가 적어지는 효율성이 있습니다.

🧯문제

아래 가이드에 따라 딥러닝을 학습하고 정확도를 작성하시오

  • 작업 데이터 선택: 가공된 데이터를 사용하세요
  • Input 칼럼
    • 연도, 시도, 학교급, 학년_IM, BMI는 제외 컬럼으로 지정
    • 범주형 변수는 데이터 인코더를, sparse로 설정
  • Output 칼럼 : 종속변수를 Output로 설정
  • 칼럼 parameter설정
    • 데이터 유형은 모델 유형에 맞게 설정하시오
    • FC레이어수:2. FC레이어크기:100, 드롭아웃0, 활성화함수 relu
  • 학습 Parameter 설정 : Epochs:2, Batch size:128, Early Stop:5, Optimizer: adam, Learning Rate:0.001, 교차검증 fold수 :1
  • 답안작성
    • 모델 학습후 오른쪽 상단의[모델저장 ]기능을 ㅌㅇ해 모델을 저장하시오
    • 정답 작성은 반올림하여 소숫점 넷째 자리까지 작성하시오
