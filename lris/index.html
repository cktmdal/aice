문제 정의 (Problem Definition)

목표: 붓꽃(Iris)의 4가지 측정 데이터(꽃받침 길이/너비, 꽃잎 길이/너비)를 활용하여 붓꽃의 품종을 자동으로 분류하는 인공지능 모델을 개발합니다.

분류 대상 품종 (Target Classes):

  • Setosa (세토사)
  • Versicolor (버시컬러)
  • Virginica (버지니카)

기대 효과: 지도학습(Supervised Learning) 중 다중 클래스 분류(Multi-class Classification) 모델의 구조를 이해하고, 인공신경망의 학습 과정을 파악할 수 있습니다.

실습에 사용할 정제된 붓꽃 원본 데이터를 불러옵니다.

  • 전체 샘플 수: 150행 (각 품종당 50개)
  • 결측치 (Missing Values): 없음 (0건)
  • 특성 변수 (Feature Type): 수치형(Numerical) 4개, 범주형(Category) 1개

데이터 가공 (Data Preprocessing)

모델 학습 효율을 높이기 위해 입력 데이터를 정규화(Normalization)하고, 정답 레이블을 원-핫 인코딩(One-hot Encoding) 처리합니다.

  • 특성 스케일링: Min-Max 정규화 적용 (0~1 범위로 변환)
  • 데이터 분할: 학습용 데이터(Train) 80% / 테스트용 데이터(Test) 20%

딥러닝 학습 (Deep Learning Training)

인공신경망(MLP) 모델의 하이퍼파라미터를 설정하고 학습을 시작합니다.

  • output칼럼: 종류
  • 제외컬럼 : 가공전 데이터
  • 데이터유형 : category
  • 디코더 : classifier
  • 활성화 함수 : softmax
  • FC 레이어수 : 2
  • Epochs : 100
  • Optimizer : adam
