데이터 개념부터 정형·반정형·비정형 데이터의 세부 특징까지 완벽 정리

💡 1. 데이터(Data)의 개념

관찰이나 측정을 통해 수집한 사실이나 값입니다. 자동차가 연료 없이 달릴 수 없듯, 인공지능은 데이터 없이 작동할 수 없습니다.

🌡️ 주변의 데이터 예시

  • 오늘 기온: 23°C (기상청 측정 수치)
  • 편의점 구매 기록: 언제, 무엇을, 얼마에 샀는지
  • 건강검진 결과: 혈압, 심박수, 혈당 수치
  • GPS 위치 정보: 위도와 경도 좌표

🎨 데이터의 형태

데이터는 숫자에만 국한되지 않으며, 숫자, 문자, 이미지, 소리 등 다양한 형태로 존재합니다.

✨ 우리는 매일 데이터를 만들고 사용하고 있습니다!

🗂️ 2. 데이터의 유형 (형태별 분류 개요)

데이터는 구조와 형태에 따라 크게 3가지로 나뉩니다. (전 세계 데이터의 약 80%는 비정형 데이터입니다.)

점유율 20%

📊 정형 데이터 (Structured)

행과 열로 깔끔하게 정리되어 미리 정해진 형식(스키마)이 있는 데이터

예시: 엑셀, 성적표, 매출 기록

점유율 10%

🏷️ 반정형 데이터 (Semi-Structured)

일정한 규칙(태그/키 구조)은 있으나 표로 정형화하기는 어려운 데이터

예시: JSON, XML, HTML, 이메일

점유율 70%

🖼️ 비정형 데이터 (Unstructured)

정해진 구조 없이 자유로운 형태로, AI가 처리하려면 숫자로 변환하는 전처리가 필요함

예시: 사진, 영상, 음성, SNS 글

02 📊 정형 데이터 Structured Data

행(Row)과 열(Column)로 깔끔하게 정리된 데이터

이름 나이 키(cm) 좋아하는 과목
김민수15168수학
이서연16155과학
박지호15172영어

➡️ 열(Column) = 속성 (이름, 나이 등)
➡️ 행(Row) = 개별 데이터 한 건

정형 데이터의 특징

1
규칙적 구조
미리 정해진 형식(스키마)이 있다
2
빠른 검색
특정 값을 빠르게 찾을 수 있다
3
분석 편리
통계, 그래프 등으로 바로 활용 가능
4
대표 저장소
데이터베이스(DB), 엑셀, CSV

📌 데이터 테이블 용어 및 입력/출력 변수 정리

📌 행 = 케이스 = 관측치 = 샘플 = 레코드
이름 키(cm) 몸무게(kg) 공부시간(h) 합격여부
김철수175685합격
이영희162553불합격
박민수180757합격
⬇️
입력(독립) 변수 (X) : 속성 = 특성 = 변수 = 피처(Feature) = 컬럼
⬇️
출력(종속) 변수 (y) : 속성 = 레이블 = 타겟(Target)

📥 입력 변수 (X)

AI가 학습에 사용하는 정보 (예: 키, 몸무게, 공부시간)

📤 출력 변수 (y)

AI가 맞추려 하는 정답 (예: 합격 여부)

03 🏷️ 반정형 데이터 Semi-structured Data

키(Key)와 값(Value) 쌍으로 구성된 데이터 (대표 예시: JSON, XML, HTML, 이메일, 로그 파일)

{
  name    : "김민수",
  age     : 15,
  scores : [
    { subject : "수학", score : 92 },
    { ... }
  ]
}

data.json 구조 예시

반정형 데이터의 특징

1
태그/키 구조
데이터에 이름표(태그)가 붙어 있음
2
유연한 구조
항목마다 필드가 다를 수 있음
3
중첩 가능
데이터 안에 데이터를 넣을 수 있음
4
변환 필요
분석하려면 정형으로 변환해야 함

04 🖼️ 비정형 데이터 Unstructured Data

정해진 구조 없이 자유로운 형태의 데이터

비정형 데이터의 종류

📷
이미지: 사진, 그림, 스캔 문서
픽셀 단위 색상 정보 (얼굴 사진, X-ray 등)
📄
텍스트: 자연어로 쓰인 문서
길이와 구조가 자유로움 (뉴스 기사, 리뷰)
🎵
음성: 소리의 파동을 기록한 시계열 데이터
통화 녹음, 음악, 팟캐스트
🎬
영상: 이미지 + 음성이 결합된 시간 흐름 데이터
유튜브, CCTV, 드라마

⚠️ 핵심 포인트

"인공지능이 비정형 데이터를 처리하려면, 먼저 숫자로 변환하는 전처리(Preprocessing) 과정이 필요함!"

📐 6. 성질별 데이터 유형 (수치형 vs 범주형)

데이터의 값이 어떤 성질을 가지느냐에 따라 2가지로 나뉩니다.

📏 수치 데이터 (Numerical)

크기 비교와 수학 연산이 가능한 데이터

  • 연속형 (Continuous): 키(168.5cm), 몸무게, 기온 등 소수점 가능
  • 이산형 (Discrete): 학생 수(35명), 형제 수 등 정수만 가능

🏷️ 범주 데이터 (Categorical)

종류나 그룹을 구분하는 데이터

  • 명목형 (Nominal): 혈액형(A, B, O, AB), 성별 (순서 없음)
  • 순서형 (Ordinal): 학점(A > B > C), 만족도 (순서 있음)
