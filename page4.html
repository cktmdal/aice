⚖️ 2. 인공지능의 분류

"사람이 규칙을 입력하는가, 데이터에서 스스로 배우는가?"

규칙 기반 (Rule-based)

사람이 규칙 작성 ➡️ 컴퓨터 실행

예: 스팸 필터
IF "무료" in 제목 ➡️ 스팸
IF "당첨" in 본문 ➡️ 스팸

한계:
• 모든 규칙을 사람이 만들어야 함
• 복잡한 패턴은 규칙화가 불가능
• 새로운 패턴에 대응 어려움

학습 기반 (Learning-based)

데이터 제공 ➡️ 인공지능이 규칙 발견

예: 수천 건의 메일 데이터를 주면 인공지능이 스스로 스팸의 패턴을 찾아냄.

장점:
• 데이터만 있으면 복잡한 패턴도 학습
• 새로운 데이터에 유연하게 대응
• 사람이 발견 못한 패턴도 찾음

🧠 3. 인공지능에서의 학습

학습(Learning) = 알고 있는 데이터를 통해 패턴을 파악하고, 모르는 것을 알아내는 것

인공지능이 수많은 데이터(경험)를 분석하여 데이터 속에 숨겨진 규칙(패턴)을 스스로 찾아내고, 이를 통해 새로운 상황을 예측하거나 판단하는 능력

사람의 학습 (경험이 많을수록 ➡️ 판단력 향상)

📖 경험/공부 (책, 문제집)
➡️
🧠 뇌에서 이해 & 생각 (패턴 파악)
➡️
🎓 지능 향상 (새 문제 해결)

인공지능의 학습 (데이터가 많을수록 ➡️ 예측력 향상)

💾 데이터 입력 (Input Data)
➡️
🤖 모델 학습 (Training) 패턴 학습
➡️
📈 예측/판단 새 데이터 예측

사람 : 경험 ➡️ 능력치의 뇌   ≈   인공지능 : 데이터 ➡️ 모델
